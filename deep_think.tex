\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This book is not a textbook.

It is not intended to teach programming, algorithms,
or software engineering.

Instead, it asks a different question.

How does humanity discover an idea that permanently
changes the way we think?

Most inventions improve existing technology.

A few discoveries redefine reality.

The purpose of this book is to understand those discoveries.

This is a book about intellectual revolutions.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\chapter*{Manifesto}
\addcontentsline{toc}{chapter}{Manifesto}

Every generation produces thousands of useful ideas.

Only a handful permanently change the language in which
future generations think.

Computer science has produced many such ideas.

These ideas were initially counterintuitive.

Many appeared impossible.

Many contradicted common sense.

Yet today they are taken for granted.

This book attempts to reconstruct those moments of genius.

The objective is not merely to explain the final theorem.

The objective is to understand

\begin{itemize}

\item What question was humanity unable to answer?

\item Why was the question difficult?

\item What assumptions prevented progress?

\item What conceptual leap solved the problem?

\item Why did that leap appear obvious only afterwards?

\item What new worldview emerged?

\end{itemize}

\chapter*{Selection Criteria}

Every chapter must satisfy ALL of the following.

\begin{enumerate}

\item Introduced an entirely new conceptual framework.

\item Permanently changed computer science.

\item Influenced mathematics, engineering,
or philosophy.

\item Still surprises experts today.

\item Represents an act of extraordinary human creativity.

\item Cannot be replaced by a merely better algorithm.

\end{enumerate}
